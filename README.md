# Aura IDE

> Ультра-легкий, быстрый и современный редактор кода с эстетикой macOS, мощью Monaco Editor и встроенным ИИ-ассистентом на базе Google Gemini.

---

## Ключевые возможности

### 1. Ядро Monaco Editor & Производительность
- **VS Code шорткаты и возможности**: мультикурсор (`Alt+Click`, `Ctrl+D`), свертывание блоков кода, миникарта, автодополнение, подсветка парных скобок.
- **Двухоконный режим (Split Editor)**: параллельный просмотр и редактирование двух файлов.
- **Встроенный Diff Editor**: визуальное сравнение изменений в коде (Side-by-Side).
- **Интеллектуальный Copilot**: автодополнение кода на лету с помощью Gemini 3.1 Flash-Lite (`Alt+\` или авторежим).

### 2. Встроенный ИИ-ассистент (Gemini 3.1 Flash-Lite)
- **Система независимых диалогов (Multi-Chat)**: создание, переключение и удаление отдельных тредов общения с автоматическим присвоением названий.
- **Контекстное понимание кода**: мгновенные действия «Объяснить», «Найти баги», «Оптимизировать» и «Тесты» с передачей контекста открытого файла.
- **Чистый Markdown-рендеринг**: заголовки, списки, выделение жирным шрифтом без лишних символов, стилизованные блоки кода с кнопками «Скопировать» и «Вставить в файл».
- **Интеграция поисковых сервисов**: быстрые вкладки Google AI Search (`udm=50`) и DeepSeek.

### 3. 13 Тщательно подобранных тем оформления
Сквозная синхронизация интерфейса, токенов подсветки синтаксиса в Monaco и ANSI-палитры встроенного терминала:

- **Gruvbox Dark**

### 4. Встроенный терминал (ConPTY + WebSocket)
- Прямое подключение к нативному Windows ConPTY через `node-pty`.
- **Изоляция истории PowerShell**: запуск с параметром `-HistorySaveStyle SaveNothing` предотвращает загрязнение системного файла `ConsoleHost_history.txt`.
- Поддержка интерактивных программ, ANSI-цветов, динамического ресайза окна и буфера обмена (`Ctrl+C` при выделении / `Ctrl+V`).

### 5. Запуск кода и многоязычные компиляторы
- Автоматическое обнаружение установленных компиляторов и интерпретаторов: Python (включая виртуальные окружения `.venv`), Rust (`cargo run`), C/C++ (`gcc`/`g++`), Go, C# (`dotnet run`), Node.js / TypeScript.
- Выполнение в изолированной вкладке запуска без конфликтов путей.

### 6. Нативный Windows-лаунчер (`AuraIDE.exe`)
- Автономное WPF-приложение на базе Microsoft WebView2.
- Кастомный frameless-дизайн с поддержкой перетаскивания окна, кнопок управления окном и полноэкранного режима (`F11`).

## Установка и запуск

### Требования
- **Node.js**: версии 18+
- **ОС**: Windows 10/11 (для нативного лаунчера требуется .NET Framework 4.8 и WebView2 Runtime)

### Быстрый старт из исходников

```bash
# 1. Клонирование репозитория
git clone https://github.com/<ваш-аккаунт>/aura-ide.git
cd aura-ide

# 2. Установка зависимостей
npm install

# 3. Сборка фронтенда
npm run build

# 4. Запуск сервера
npm start
```
Сервер запустится по адресу: `http://localhost:3001`

### Запуск нативного приложения
Дважды кликните `AuraIDE.exe` или запустите `start.bat`.
